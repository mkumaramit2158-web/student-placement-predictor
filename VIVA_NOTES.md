# Quick Viva Notes

1. **Project:** Estimates likely student placement outcome from academic and skill inputs.
2. **Algorithm:** Logistic Regression, a supervised binary classification algorithm.
3. **Why this algorithm?** The target has two classes: Placed and Not Placed.
4. **Features:** CGPA, aptitude, technical skills, communication skills, internships and projects.
5. **Target:** `placed` — 1 means Placed; 0 means Not Placed.
6. **StandardScaler:** Standardizes numeric input features.
7. **Train/test split:** Fits on training records and evaluates on held-out records.
8. **Accuracy:** Fraction of test predictions that are correct. Here 84.29% on synthetic data only.
9. **Streamlit:** Python framework for creating an interactive web app.
10. **Limitation:** Synthetic data is only for demonstration; it cannot prove real placement chances.
